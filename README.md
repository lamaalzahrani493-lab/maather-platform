# 📋 تقرير توثيقي: منصة «مآثر» (Maather Platform)

## 📌 1. نبذة عن المشروع

**منصة «مآثر»** هي نظام ويب متكامل مصمم للبيئة التعليمية والإدارية، وهدفه الأساسي أتمتة وتنظيم عملية **توثيق شواهد الأداء الوظيفي** في المدارس. تعمل المنصة على نقل العمل الإداري من الأرشفة الورقية التقليدية إلى السحابة الرقمية الذكية، مما يوفر بيئة عمل سلسة وموثوقة للمعلمات، ويُسهل على الإدارة عمليات المراجعة، التقييم، واستخراج التقارير بدقة عالية.

---

## 👥 2. الأدوار والصلاحيات في النظام

يعتمد النظام على **رمز مدرسة فريد** لضمان عزل وفلترة بيانات كل مدرسة بشكل آمن ومستقل تماماً:

* **المعلمة (`teacher_login.php`):** رفع الشواهد المهنية، متابعة نسب الإنجاز الفورية، واستكمال التسليم النهائي للملفات.
* **قائدة المدرسة / المديرة (`admin_login.php`):** مراجعة وتقييم الشواهد، إدارة المؤشرات، متابعة حالة المعلمات، وإصدار التقارير الشاملة.
* **الوكيلة والموجهة الطلابية (`staff.php`):** بوابات مستقلة مخصصة بنماذجها الخاصة لتقييم المؤشرات والمتابعة الإشرافية.

---

## ⚙️ 3. رحلة العمل والخصائص الأساسية

1. **الرفع والإرفاق المرن:** تستطيع المعلمة إرفاق الشواهد عبر رفع ملفات (صور أو PDF)، أو إضافة روابط إلكترونية خارجية، أو كتابة ملاحظات نصية مباشرة.
2. **التقيم والمراجعة الدقيقة (Review & Rating):** تتيح للمديرة استعراض كل شاهد مرفق، وتقييمه رقمياً، إما **باعتماده** إن كان مستوفياً للشروط، أو **إرجاعه** مع إرفاق ملاحظات توجيهية للمعلمة لتعديله.
3. **الباركود الذكي (Code128):** يقوم النظام آلياً بتحويل روابط الشواهد والملفات إلى رموز باركود فريدة تطبع ضمن التقارير والسجلات المطبوعة، مما يتيح لأي شخص مسح الباركود بكاميرا الجوال للوصول للملف الرقمي فوراً.
4. **مركز التحليلات والإكسل الذكي:** منصة تحليلات داخلية تحسب نسب الإنجاز، تحدد الفجوات وأضعف المؤشرات، وتوفر إمكانية تصدير البيانات إلى ملفات Excel احترافية ومنظمة.
5. **الطباعة المدمجة والمخصصة:** صفحات مصممة خصيصاً ومجهزة بالمنسق البرمجي لطباعة تقارير المؤشرات وأداء المعلمات أو التقرير الختامي للمدرسة بدقة وجاهزية تامة.

---

## 🛡️ 4. الأمان وحماية البيانات

* عزل تام لبيانات المدارس باستخدام رموز المدارس الفريدة.
* تأمين الجلسات، التحقق من صلاحيات الدخول، وفحص محتوى الملفات والروابط لضمان سلامة الاستضافة.
* تخزين مسارات الملفات في قواعد البيانات وحفظ الملفات الفعلية في مجلدات مخصصة لضمان سهولة النسخ الاحتياطي الكامل.
